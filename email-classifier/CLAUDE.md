# 이메일 분류 작업 지침

담당 계정(admission@yu.ac.kr)으로 들어오는 메일을 내용에 따라 카테고리별로 분류하고, 한눈에 보기 쉽게 정리한다.

## 작업 원칙

1. 정보가 충분하면 되묻지 말고 바로 실행한다.
2. 결론부터 말한다.
3. 근거가 있는 것만 보고한다. 확인하지 못한 것은 확인 못 했다고, 실패했으면 실패했다고 말한다.
4. 사용자가 설명하거나 질문하는 중이면 판단만 내놓는다. 찾은 것을 보고하고 멈춘다. 고쳐 달라는 요청이 있기 전에는 고치지 않는다.

## 카테고리

### 우리 부서 관할: 1. 학부

학부 문의는 아래 세부 유형으로 나눈다.

| 세부 유형 | 해당 내용 | 처리 | Gmail 라벨 |
|---|---|---|---|
| 지원사항·장학 | 신입·편입 지원 방법, 장학금, 기숙사, 어학 요건(TOPIK·IELTS·MOI·세종학당), 학업 공백, 영어트랙 여부, 유학원의 모집요강 요청 | 모집요강 송부로 처리 가능 | `분류/1 학부` |
| 학위 인정 여부 | 출신 학교의 학위·학력(디플로마, HND, BTS, 외국 전문대, 외국 대학 재학 학점 등)이 입학·편입에 인정되는지 | 담당자가 증빙과 상황을 보고 직접 판단 | (라벨 미정) |
| 서류 문의 | 입시기간 추가 서류 문의, 본인 서류 제출 가능 여부(가족관계 증명, 여권, 방문 제출 등) | 직접 처리 | `분류/1 학부/서류 문의` |
| YU TOPIK | YU TOPIK 시험 접수·일정·환불, 우리 부서 시험 안내에 대한 회신 | 직접 처리 | `분류/1 학부/YU TOPIK` |
| 협력 요청 | 유학원·기관의 MOU·파트너십·학생모집 협력 제안, 박람회 홍보, 포럼·커뮤니티 초대, 항공권 등 상업성 제휴 제안 | 직접 처리 | `분류/1 학부/협력 요청` |
| 기타 | 입학이 아닌 재학·학사 문의(예: 학부 연구기회) | 직접 처리 | `분류/1 학부` |

- 하위 라벨을 붙일 때는 상위 라벨 `분류/1 학부`도 함께 붙여야 학부 화면에서 함께 보인다(사용자 확인 전).
- 학부 입학 문의와 협력 제안이 섞인 유학원 메일은 주된 내용으로 판단한다. 입학 정보 요청이 중심이면 지원사항·장학, 모집 협력 신청이 중심이면 협력 요청.

### 타 부서 전달: 2~5

| # | 카테고리 | 해당 내용 | Gmail 라벨 | 전달 주소 (기존 전달 이력에서 확인) |
|---|---|---|---|---|
| 2 | 대학원(일반대학원) | 석·박사 입학, 대학원 장학, 대학원 지원서 문제 | `전달/2 대학원` | graduate@yu.ac.kr (대학원국제팀) |

| 4 | 한국어국제교육연수원 | 한국어 과정, 연수원 등록금 환불 | `전달/4 한국어연수원` | kli@ynu.ac.kr |

- 실제 전달(메일 발송)은 사용자가 지시할 때만 한다. 분류와 라벨 작업만으로는 전달하지 않는다.

### 그 외

| 분류 | 해당 내용 | Gmail 라벨 |
|---|---|---|
| 확인 필요 | 아래 "미확정 기준"에 걸리는 메일 | `분류/확인 필요` |
| 미분류 | 보안 알림, 타 대학 앞으로 온 메일, 구직, 내부 업무 메일, 과정이 불분명한 개인 문의, 뉴스레터성 홍보 | `분류/미분류` |

어느 카테고리에도 해당하지 않거나 내용만으로 판단할 수 없는 메일은 `미분류`로 두고 그 이유를 적는다. 추측해서 끼워 넣지 않는다.

## 분류 절차

1. 메일마다 제목과 본문을 읽고 카테고리 하나를 정한다. 학부면 세부 유형까지 정한다.
2. 분류 근거를 메일 속 표현으로 짧게 남긴다 (예: "'HND', 'Bachelor's' 언급").
3. 제목·미리보기로 판단이 어려우면 본문을 열어 확인하고, 근거에 '본문:'을 표시한다.
4. 한 메일에 여러 문의가 섞여 있으면 주된 문의로 분류하고, 나머지 카테고리는 `부가`로 표시한다.
5. 판단이 애매하면 아래 "미확정 기준"에 해당하는지 확인하고, 해당하면 `확인 필요`로 표시한다.
6. Gmail에는 라벨만 붙인다. 받은편지함 위치·읽음 상태는 바꾸지 않는다.

## 출력 형식

결과는 아래 순서로 정리한다.

1. **요약**: 전체 메일 수, 카테고리별 건수, 우리 부서 처리 건수와 타 부서 전달 건수
2. **우리 부서 처리 (학부)**: 세부 유형별 표
3. **타 부서 전달 (2, 3, 4, 5)**: 카테고리별 표, 아직 전달 기록이 없는 건 표시
4. **미분류 / 확인 필요**: 표와 사유

표 항목:

| 받은 날짜 | 보낸 사람 | 제목 | 카테고리 | 부가 카테고리 | 분류 근거 | 처리 현황 |
|---|---|---|---|---|---|---|

결과 파일은 `email-classifier/results/`에 저장한다. 지원자 이메일 주소가 들어 있으므로 git에 올리지 않는다(`.gitignore` 처리됨).

## 미확정 기준 (사용자 확인 전)

아래 경우는 기준이 정해지지 않았다. 임의로 정하지 말고 `확인 필요`로 표시하거나 ※로 표시해 보고한다.

- **학부 vs GKS**: 학부 입학 문의와 GKS 지원 문의가 함께 들어 있는 경우
- **대학원 vs GKS**: 석사 입학과 GKS-G 장학을 함께 묻는 경우
- **대학원 vs PSPS**: 과정명이 불분명한 석사 장학 문의(예: 특정 국가 대상 석사 장학)
- **국내 전문학사 편입**: 국내 전문대 졸업(예정)자의 편입 문의를 '지원사항·장학'으로 볼지 '학위 인정 여부'로 볼지. 현재는 지원사항·장학으로 분류
- **학위 인정 여부 라벨**: Gmail 라벨 이름과 위치 미정

기준이 정해지면 이 절을 갱신한다.
