# 매일 9시 자동 분류: 예약 작업 설정 방법

## 지금 상태

- 예약 작업 이름: `admission 메일 매일 라벨 분류` (ID `trig_01EY4C6ueBXAVxasM8X2TTL7`)
- 실행 시각: 매일 09:00 KST, 실행할 때마다 새 세션
- 문제: 이 예약 작업에는 Gmail 커넥터가 연결되어 있지 않다(`mcp_connections: []`).
  - 2026-10-22 11:23 KST 테스트 실행 결과: "Gmail 커넥터가 이 세션에 없어 실행하지 못함"
  - 계정에는 Gmail이 연결되어 있다(claude.ai 커넥터 화면에 "연결 해제" 버튼이 보임). 그러나 예약 작업은 계정 연결을 자동으로 쓰지 않고, 작업마다 커넥터를 따로 지정해야 한다.
  - 이 예약 작업은 Claude가 대화 세션에서 만들었는데, 그 세션에는 예약 작업에 커넥터를 붙일 권한이 없었다. 그래서 사용자가 claude.ai 화면에서 직접 연결해야 한다.

## 설정 방법

화면의 정확한 메뉴 이름과 위치는 Claude가 직접 확인하지 못했다. 아래와 다르면 화면을 캡처해 Claude에게 보여 준다.

### 방법 A: 기존 예약 작업에 Gmail 추가 (먼저 시도)

1. claude.ai에서 Claude Code 화면으로 들어가 예약 작업(Routines / Scheduled tasks) 목록을 연다.
2. `admission 메일 매일 라벨 분류`를 선택하고 편집한다.
3. 커넥터(Connectors) 항목에서 Gmail을 추가하고 저장한다.

### 방법 B: 새로 만들기 (편집 화면에 커넥터 항목이 없을 때)

1. 같은 예약 작업 화면에서 새 예약 작업을 만든다.
2. 아래처럼 설정한다.
   - 이름: `admission 메일 매일 라벨 분류`
   - 일정: 매일 오전 9시, 시간대 Asia/Seoul (한국 시간)
   - 실행 방식: 실행할 때마다 새 세션
   - 커넥터: Gmail (admission@yu.ac.kr 계정)
   - 지시문: 이 파일 맨 아래 "지시문 전문"을 그대로 붙여 넣는다.
3. 저장한 뒤 Claude에게 알린다. 중복 실행을 막기 위해 기존 예약 작업(`trig_01EY4C6ueBXAVxasM8X2TTL7`)은 Claude가 삭제한다.

### 설정 후 확인

1. Claude에게 "예약 작업 지금 실행해서 확인해줘"라고 요청한다.
2. 실행 결과에 "Gmail 커넥터가 이 세션에 없어 실행하지 못함"이 아니라 라벨별 처리 건수가 나오면 정상이다.
3. 그 실행으로 10/22 09:00 이후 아직 라벨이 없는 메일은 처리되지 않는다(대상은 당일 09:00 이전 수신분). 해당 메일은 다음 날 9시 실행 때 처리된다.

## 지시문을 바꿔야 할 때

분류 기준이나 라벨 이름을 바꾸면 `CLAUDE.md`와 함께 예약 작업 지시문도 고쳐야 한다. 예약 작업은 저장소 파일을 읽지 않고 지시문만 보고 실행한다.
